# Ncream — Ice Cream Landing Page

Website landing page + keranjang belanja yang terhubung ke **Google Sheets** sebagai database.

## Setup singkat

1. Ikuti instruksi di `../CARA_SETUP.md`
2. Paste URL Apps Script Web App ke `script.js` → `CONFIG.APPS_SCRIPT_URL`
3. Upload folder ini ke GitHub Pages

## Fitur

- Katalog produk dinamis dari Google Sheet
- Filter kategori + search
- Keranjang + checkout (simpan order ke Sheet + buka WhatsApp)
- Multi bahasa ID / EN
- Responsive
