# Ncream — Ice Cream Landing Page

File:
- index.html — struktur halaman
- style.css — desain/responsive
- script.js — slider, bahasa, search, filter, keranjang, dan WhatsApp checkout

Cara menjalankan:
1. Simpan ketiga file dalam folder yang sama.
2. Buka `index.html` di Chrome/Edge.
3. Pastikan koneksi internet aktif karena foto dan font menggunakan hotlink dari internet.

Catatan:
- Foto sementara menggunakan URL gambar Unsplash untuk kebutuhan demo.
- Nomor WhatsApp yang dipakai: +6285691428657.
- Tombol WhatsApp menggunakan template: "Halo kak aku mau pesan roti .... 5 pack ya;"
- Checkout dari keranjang otomatis membuat pesan berdasarkan produk yang dipilih.

- favicon.svg & favicon.png — favicon Ncream untuk tab browser.
